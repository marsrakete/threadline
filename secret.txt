DM-Archiv Secret-Verhalten

Aktueller Stand:
- Der Pseudo-Schutz fuer das DM-Archiv ist derzeit deaktiviert.
- Das DM-Archiv ist deshalb normal im Workspace erreichbar, sobald ein Account verbunden ist.

Die Soft-Gate-Funktion bleibt aber im Code erhalten und kann spaeter wieder aktiviert werden.

So funktioniert das Gate im Code:
- Das DM-Archiv kann ueber einen URL-Parameter oder URL-Hash freigeschaltet werden.
- Unterstuetzt werden:
  - ?DMSECRET=DMSECRET
  - #dmsecret=DMSECRET

Pruefung:
- Das eingegebene Secret wird im Browser mit SHA-256 gehasht.
- Der Hash wird mit dem im Code hinterlegten Hash verglichen.
- Nur bei Uebereinstimmung wird der DM-Bereich sichtbar.

Frueheres Verhalten nach erfolgreicher Freischaltung:
- Die Freischaltung wurde in der laufenden Browser-Session gespeichert.
- Dadurch blieb das DM-Archiv auch nach dem Neuladen der Seite sichtbar,
  solange dieselbe Session aktiv war.
- Das Secret wurde danach aus der URL entfernt.

Wichtig:
- Das ist nur ein Soft-Gate zum Verbergen der Funktion.
- Es ist keine echte Sicherheitsmassnahme gegen technisch versierte Nutzer.

Technische Hinweise:
- Schalter in app.js:
  - DM_ACCESS_GATE_ENABLED
- Session-Speicher-Schluessel:
  - threadline:dm-access
- Weitere relevante Konstanten in app.js:
  - DM_ACCESS_QUERY_PARAM
  - DM_ACCESS_HASH_PARAM
  - DM_ACCESS_SESSION_KEY
  - DM_ACCESS_SECRET_HASH

Wenn das DM-Archiv spaeter wieder verborgen sein soll:
- DM_ACCESS_GATE_ENABLED in app.js wieder auf true setzen.
